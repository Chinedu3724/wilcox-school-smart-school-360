# WILCOX SCHOOL – SMART SCHOOL 360

**Tagline:** Learning Today. Leading Tomorrow.

## About the Project
WILCOX SCHOOL – SMART SCHOOL 360 is a modern school website designed to improve access to school information, academic programmes, STEM activities, news, and announcements.

## Problem It Solves
It provides a central platform where parents, students, teachers, and visitors can easily access important school information.

## Technologies Used
- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive features
- Node.js – Backend development
- Express.js – Server framework
- SQLite – Database

## Current Features
- School homepage
- About the school
- Academic programmes
- STEM Centre
- News and events
- Contact section
- Responsive navigation

## Planned Features
- Student portal
- Administrator dashboard
- Online examination system
- Student account management

## Project Status
Frontend development is in progress. Backend and additional school management features are under development.
